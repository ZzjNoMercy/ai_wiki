# 第一性原理（Prompt 技巧）

## 定义

Vibe Coding 中"管生成"的 Prompt 技巧：平时怎么说就怎么说，只需要在最后加一句"从第一性原理出发"。作者称加了这一句话后，Agent 写方案、找 BUG 的能力都进化了一大截。

## 机制

当前 AI 很多仍是在做类比推理：让它写一个过滤函数，它会在训练数据里找到几万个类似的函数，然后写一个"看起来差不多"的。这个过程很快、结果也能用，但跳过了最关键的步骤——"这个问题真的应该这么解吗？"。"从第一性原理出发"这七个字强制打断 AI 的类比推理，逼它回到问题的本质，不要参考别人的方案，从最基本的事实出发重新推导。

## 例证（AIHOT 流量路由）

作者自研产品 AIHOT 的飞书推送事故中，Agent 的初步修复只是把 OpenAI 的抓取单独修好（治表）；追加"根据第一性原理来找一下原因"后，找到了海外信源抓取规则中流量路由层面的深层隐患。作者判断若只修表层，未来其他信源还会出问题，"缝缝补补，最后堆成一座屎山"，于是花半天时间把底层路由直接重构（治本）。

## 思想渊源（文中所述）

- 作者称这个道理亚里士多德两千多年前就说过。
- 马斯克把这套思维用在 SpaceX：当时行业共识是"火箭发射就是得花几个亿"，马斯克从原材料（铝合金、碳纤维、航空级燃料）成本重新算起，重新设计整个制造流程，发射成本降了 90%。
- GitHub 上已有人做了专门的 skill（first-principles），但作者认为无需安装 skill 或写 System Prompt，在需要时（解决问题、修 BUG、让 AI 设计架构）于 Prompt 后加一句即可；只要任务稍微复杂一点，这个 Prompt 几乎万能。

## 核心一句话

回到最根本的事实重新推导。

## 与其他概念的关系

- 与 [[concepts/adversarial-review|对抗式审查]]（relates_to）共同构成作者心目中 Vibe Coding 的两大基石，合在一起构成完整闭环：前者管生成、后者管验证。
- 属于 [[concepts/vibe-coding|Vibe Coding]]（relates_to）领域的核心 Prompt 技巧。

## 应用范围（文中所述）

作者认为应用范围不止 Vibe Coding：做完一个商业方案，可以让 AI 从第一性原理出发审视方案、剥掉所有假设、质问核心逻辑是否成立；做人生决策（如换工作）时也可以先用第一性原理想清楚自己到底想要什么。
