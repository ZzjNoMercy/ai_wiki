# Agent Client Protocol 官方教程（Get Started）

- 标题/署名：Agent Client Protocol 官网发布的入门教程（Get Started）。
- 发布平台：Agent Client Protocol 官网（agentclientprotocol.com）。
- 原文 URL：https://agentclientprotocol.com/（入门教程：/get-started/introduction、/get-started/architecture、/get-started/agents、/get-started/clients、/get-started/registry；语言库见官网 Libraries 章节）。
- 收录说明：本页依据 conversationsynthesis 会话记录（query-188aaa0b1421）编译，该记录整理自 ACP 官网入门教程。

## 内容结构

- **Introduction（简介）**：ACP 标准化代码编辑器/IDE 与编码智能体之间的通信，适用于本地和远程场景；本地智能体作为编辑器子进程（stdio + JSON-RPC），远程智能体托管在云端或独立基础设施（HTTP/WebSocket，完整远程支持仍在开发中）。
- **Architecture（架构）**：三条设计原则（MCP 友好、UX 优先、可信模型）、连接方式（Setup）与 MCP 集成方式。
- **Agents**：官方列出的 ACP 兼容智能体列表。
- **Clients**：官方列出的客户端、框架、连接器与周边工具列表。
- **ACP Registry**：经过人工审核的 ACP 兼容智能体注册表（GitHub `agentclientprotocol/registry`）。
- **Libraries**：官方语言库（Kotlin、Java、Python、Rust、TypeScript 等）与社区库列表。
