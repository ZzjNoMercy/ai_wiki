## 内容概述

本文是一篇围绕 harness engineering 如何贡献于 recursive self-improvement（RSI）的研究综述，主要结构：

- discusses → [[concepts/harness|Harness（模型外层执行系统）]]：本文给出 Harness 定义、设计模式、优化对象与自我改进边界。

- Harness 设计模式：工作流自动化、文件系统作为持久记忆、[[concepts/multi-agent|子 Agent]] 与后台任务，以及编码 Agent Harness 的主流工具接口（见 [[media/harness-engineering-for-self-improvement|Harness Design Patterns]]）。
- Context Engineering：Agentic Context Engineering（[[media/harness-engineering-for-self-improvement|ACE]]）、Meta Context Engineering（[[media/harness-engineering-for-self-improvement|MCE]]）、Meta-Harness（[[media/harness-engineering-for-self-improvement|Meta-Harness]]）。
- Workflow Design：AI Scientist（[[media/harness-engineering-for-self-improvement|AI Scientist]]）、ScientistOne（[[media/harness-engineering-for-self-improvement|ScientistOne]]）、Autodata（[[media/harness-engineering-for-self-improvement|Autodata]]）、ADAS（[[media/harness-engineering-for-self-improvement|ADAS]]）、AFlow（[[media/harness-engineering-for-self-improvement|AFlow]]）。
- Self-Improving Harness：Self-Taught Optimizer（[[media/harness-engineering-for-self-improvement|STOP]]）、Self-Harness（[[media/harness-engineering-for-self-improvement|Self-Harness]]）、Agentic Harness Engineering（[[media/harness-engineering-for-self-improvement|AHE]]）。
- Evolutionary Search：AlphaEvolve（[[media/harness-engineering-for-self-improvement|AlphaEvolve]]）、Darwin Gödel Machine（[[media/harness-engineering-for-self-improvement|DGM]]），以及 Promptbreeder、GEPA、ThetaEvolve、DemoEvolve、ShinkaEvolve 等（见 [[media/harness-engineering-for-self-improvement|Evolutionary Program Search]]）。
- 与模型权重的联合优化：SIA（[[media/harness-engineering-for-self-improvement|SIA]]）、Continual Harness（[[media/harness-engineering-for-self-improvement|Continual Harness]]）。
- 未来挑战：弱且模糊的评估器、上下文与记忆生命周期、负结果、多样性坍缩、奖励黑客、长期成功、人类角色；以及 LLM 自主科研的失败模式（[[media/harness-engineering-for-self-improvement|自主科研失败模式]]）。
