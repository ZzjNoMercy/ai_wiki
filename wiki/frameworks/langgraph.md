# LangGraph

LangGraph 为 [[frameworks/deepagents|DeepAgents]] 提供持久执行、状态、流式处理和 Human-in-the-loop 运行时；DeepAgents 使用 LangGraph 作为运行时（uses）。

`HarnessProfile` 是 DeepAgents 的运行适配配置，它不是 Middleware，也不是新的 LangGraph 节点。
